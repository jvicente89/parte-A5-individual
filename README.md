# Parte Operativo Valencia (Turno Noche) - Versión Móvil A5 (2 servicios/página)

## Cómo instalarla en el móvil
1. Sube `index.html` y `manifest.json` a cualquier alojamiento web HTTPS (o ábrelos desde un servidor local / GitHub Pages / Netlify).
2. **En iPhone / iPad (Safari):** Abre la página, toca el botón **Compartir** y selecciona **Añadir a pantalla de inicio**.
3. **En Android (Chrome):** Abre la página, toca el menú de tres puntos (`⋮`) y selecciona **Añadir a pantalla de inicio** o **Instalar aplicación**.

## Cambios realizados
- **Listado de calles actualizado:** Se han incorporado las **290 vías** proporcionadas (sin duplicados, ordenadas alfabéticamente), sustituyendo al callejero anterior.
- **Exportación PDF en A5 vertical (`148 × 210 mm`) a 2 servicios por página:** Cada página muestra 2 fichas de servicio con cabecera (`Turno: NOCHE`, `Día` y numeración), campos (`Unidad`, `Indicativos`, `SIRE`, `Calle`, `Hora`) y el recuadro inferior de `Actuación`.
